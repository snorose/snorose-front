# 홈 팝업

기존 공지 레이아웃 안에 게시 기간이 유효한 팝업을 노출 순서대로 함께 표시한다. 게시 기간과 숨김 만료는 KST 날짜 기준이며 시작일·종료일을 포함한다. 오늘 하루/3일간 숨기기와 일반 닫기를 유지한다. 일반 닫기는 현재 홈 방문에만 적용한다.

## 데이터와 API

제공된 문서는 관리자 전용 API뿐이므로 일반 사용자 화면에서 `/v1/admin/popups`를 호출하지 않는다. 목 데이터는 관리자 상세의 `id`, `title`, `description`, `imageUrl`, `displayOrder`, `startDate`, `endDate`, `status`, `createdAt`, `updatedAt` 필드를 따른다. 본문·이미지·수정일시는 nullable이다.

개발 환경에서는 기본으로 목 데이터를 사용한다. 진행중 2개, 예약 1개, 종료 1개를 KST 오늘 기준으로 생성하며 진행중만 표시한다. 브라우저별 숨김 설정은 기존 localStorage 키에 저장된다. 관리자 목 데이터와 자동 공유하지 않는다.

- `REACT_APP_POPUP_MOCK=true`: 목 데이터를 명시적으로 활성화한다.
- `REACT_APP_POPUP_MOCK=false`: 목 데이터를 끈다.
- `REACT_APP_POPUP_API_PATH`: 사용자 전용 조회 경로가 확정되면 지정한다. 현재 연결부는 `isSuccess/code/message/result` 응답의 `result`에 상세 필드를 가진 배열이 온다고 가정한다. 실제 사용자 API 계약을 확인한 뒤 이 부분을 맞춰야 한다. 인증이 필요한지도 확인해야 한다.

프로덕션에서는 목 데이터가 기본 비활성화된다. 조회 경로가 미설정이면 요청과 팝업을 표시하지 않는다. 로딩·빈 결과·조회 오류는 홈 화면을 가리지 않는다. API 설정 변경 후 개발 서버 재시작 또는 재빌드가 필요하다.

## 콘텐츠

관리자 미리보기와 같은 굵은 글씨·목록·문단·링크·줄바꿈을 지원한다. `markdown-it`으로 변환하고 별도 DOMPurify 인스턴스로 허용 태그만 남긴다. HTML과 위험한 프로토콜은 실행하지 않는다. 내부 링크는 SPA로 이동하고 외부 HTTP 링크는 새 탭에서 연다. 이미지는 원본 비율을 유지한다.

현재 팝업은 기존처럼 한 다이얼로그에 여러 공지를 함께 표시한다. 키보드 포커스 이동과 복원, Escape 닫기, 배경 스크롤 잠금을 제공한다. 애니메이션은 추가하지 않는다.
